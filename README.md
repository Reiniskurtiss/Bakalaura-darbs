# Kiberhigiēnas zināšanu pārbaudes prototips

Šis prototips ir izveidots mācību nolūkos, lai pārbaudītu lietotāja zināšanas par sociālās inženierijas riskiem un kiberhigiēnas pamatprincipiem. Testā iekļauti jautājumi par parolēm, daudzfaktoru autentifikāciju, e-pastu izvērtēšanu, pielikumiem, ziņošanu un drošu rīcību ikdienas situācijās.

## Projekta mērķis

Prototipa mērķis ir novērtēt lietotāja zināšanas un rīcību dažādās ar kiberhigiēnu saistītās situācijās. Pēc testa izpildes lietotājs saņem rezultātu, riska līmeņa novērtējumu un iespēju apskatīt pareizās atbildes ar paskaidrojumiem.

## Funkcionalitāte

- Jautājumi ir sadalīti pa nodaļām.
- Katrā nodaļā tiek pārbaudīta konkrēta kiberhigiēnas tēma.
- Par atbildēm tiek piešķirti punkti.
- Pēc testa izpildes tiek aprēķināts kopējais rezultāts.
- Lietotājam tiek parādīts riska līmenis.
- Lietotājs var apskatīt pareizās atbildes un paskaidrojumus.
- Daļā jautājumu atbildes tiek parādītas nejaušā secībā.
- Daļā jautājumu jāizvēlas viena atbilde, vairākas atbildes vai jāsakārto darbības pareizā secībā.

## Jautājumu kategorijas

Prototipā iekļautas šādas kategorijas:

- Paroles
- Daudzfaktoru autentifikācija
- E-pasti
- Pielikumi
- Ziņošana
- Sociālā inženierija
- Drošības paradumi
